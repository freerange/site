Week 920
========

Hello!

I'm trying to get back into a bit of a routine now that the school holidays are over (at least for a few weeks until the next ones!)
I've enjoyed some time off over the Summer but it's not always been easy to juggle work alongside childcare/holidays.
Thanks to [James][james-mead] in particular for picking up a lot of the slack in my absence.

[Mavis][] continues to be the main focus of our time.
I've been working on adding and enabling [rubocop-i18n][] so that we can ensure we're adding strings to locale files instead of hardcoding them in ruby code and templates.
I also spent a lot longer than the one word change would suggest trying to debug and fix a small bug.

James merged a mammoth (117 commits!) PR to [https://mission-patch.com][mission-patch] to allow buyers to purchase multiple mission patches in a single transaction.
James has further improvements in mind but this is a huge step forward.
Great work, James!

At the ripe old age of 12 our [Chrome extension to help explain transactions in FreeAgent][fa-txn-explainer] has been retired from the Chrome Web Store for using Manifest V2.
We've long since switched to [DoubleAgent][] to solve the problems that this extension was solving so don't have any plans to resurrect it.

I was interested to read [this software developer's take on selling software from Germany][sell-from-europe].
It sounds as though they've been frustrated by the same sorts of things we've discovered while selling mission patches and [music][jam].

Until next time.

-- Chris
